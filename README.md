# MedicSingles Magazin

Redaktionelles Online-Magazin von **MedicSingles** – der Dating-Plattform für Ärztinnen, Ärzte, Pflege- und Rettungskräfte sowie Therapeuten. Ratgeber, Promi-Ärzte-Porträts und Partnersuche-Tipps für medizinische Berufe.

Gebaut mit [Next.js](https://nextjs.org/) und [Keystatic](https://keystatic.com/), deployed auf [Vercel](https://vercel.com/).
